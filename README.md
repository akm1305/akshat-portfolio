---

## ✨ Key Highlights

- **Dark & Glassmorphic Aesthetic**: Modern UI with glowing gradients, backdrop-filters, and tailored micro-animations.
- **Dynamic Typing Animation**: Interactive hero section highlighting core analytical domains.
- **Fully Working In-Browser Project Demos**:
  1. 📊 **Netflix Viewing Activity Analysis**: Interactive telemetry dashboard with profile filters, 24-hr watch frequency charts (Chart.js), and title search.
  2. 👥 **Customer Engagement Analysis**: Multi-cohort retention engine with 8-week decay curves, Monte Carlo AI optimization uplift simulation, and heatmap matrix.
  3. 🏨 **Hotel Management System**: Full PMS web app simulation with guest registration, dynamic invoice calculation, occupancy registry, check-in/checkout, and live SQLite terminal stream.
  4. 💬 **Anonymous Chatroom Application**: Real-time WebSocket chat simulation with channel switching (`#general`, `#data-science`, `#dev-chat`), instant bubble animations, and intelligent peer bot replies.
  5. 🎵 **Spain Songs Analysis**: Spotify top charts audio explorer with interactive 6-dimension radar chart and track comparison.
- **Interactive Modals & Blog Readers**: Read articles directly within modal overlays.
- **Confetti Celebration**: Canvas-confetti celebration on resume download.
- **Responsive Across All Viewports**: Optimized for desktop, laptops, tablets, and smartphones.

## 🛠️ Built With

- **HTML5 Semantic Markup**: Accessible and SEO-optimized page structure.

- **Vanilla JavaScript (ES6+)**: Interactive modal engine, DOM manipulation, dynamic simulations.

## 💻 Running Locally

To test or preview this portfolio on your computer:

### Option 1: Double Click
Simply double-click [`index.html`](index.html) to open it in your default web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

Using Node.js (`npx serve`):
```bash
npx serve .
```

## 🌐 Free Web Hosting Instructions

### Deploy to GitHub Pages (100% Free & Automatic)
1. Push this repository to your GitHub account (see step-by-step guide below).
2. On GitHub, navigate to your repository **Settings**.
3. Under the **Code and automation** section on the left sidebar, click **Pages**.
4. Under **Build and deployment** -> **Branch**:
   - Select `main`
   - Select folder: `/(root)`
   - Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<your-repo-name>/`
